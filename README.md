# MediaBias · Türkçe haber karşılaştırma

Evidence-grounded Turkish news comparison and human annotation workspace.

Implementation in progress. The project answers what happened, where sources agree and differ, how framing shapes differences, and why readers should care. It preserves uncertain findings for review and does not infer a publisher’s ideology from its identity.

## Scope

- Import the supplied source register; retain all 53 outlets and configurable feed eligibility.
- Compare same-event reporting with literal evidence quotations.
- Separate media framing techniques from possible cognitive mechanisms.
- Review, correct, adjudicate, and export training annotations.
- Evaluate with CheckList-style minimum functionality, invariance, and directional tests.

No model can be promised perfect bias identification. Live inference requires a configured model; accuracy requires a held-out, adjudicated Turkish benchmark.
